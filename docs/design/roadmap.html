چت Goftego به یک custom element تبدیل می‌شود که با یک تگ script در هر سایتی کار می‌کند. این صفحه نشان می‌دهد کار به چه فازها و تسک‌هایی شکسته می‌شود، با چه ابزارهایی ساخته می‌شود، در نهایت چه چیزی تحویل داده می‌شود و ظاهر ویجت چطور است.

چهار فاز، هر فاز یک milestone در گیت‌هاب

شماره هر تسک همان شماره issue در گیت‌هاب است. روی هر تسک بزنید تا معیارهای پذیرش (acceptance criteria) را ببینید. با برچسب‌ها فیلتر کنید.

اگر عقب افتادید، تسک‌های با برچسب cuttable (دموی strict-csp و تایپ Vue) به نسخه 1.1 می‌روند. ایزوله‌سازی، lazy loading، دسترس‌پذیری و دموی React و HTML خالی قابل حذف نیستند.

Built goftego-widget, a framework-agnostic embeddable chat widget shipped as a Lit web component with Shadow DOM style isolation, CSS-variable theming, a 5 kB lazy loader, typed DOM events, and Playwright tests proving it works inside React, Vue and plain HTML hosts.

۵ · گردش کار در گیت‌هاب

هر تسک: issue ← branch ← PR ← CI ← merge ← Done

  1. ساخت ریپو و وارد کردن تسک‌ها

    اسکریپت setup_github.py پنج milestone، یازده برچسب و ۳۰ issue می‌سازد و همه را به یک Project board اضافه می‌کند.

  2. یک branch برای هر issue

    مثلاً 6-element-attributes از روی main.

  3. Pull request با Closes #6

    این عبارت در توضیح PR باعث می‌شود issue بعد از merge خودکار بسته شود.

  4. CI باید سبز شود

    با branch protection روی main، تا lint، تست، size و E2E پاس نشوند merge ممکن نیست.

  5. Squash merge و حذف branch

    issue بسته می‌شود، کارت در Project به ستون Done می‌رود و درصد milestone بالا می‌رود.
