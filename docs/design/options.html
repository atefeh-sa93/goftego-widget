پنج جهت دیزاین برای ویجت

هر قاب یک سایت میزبان فرضی است با پنل باز، و زیرش حالت بسته (فقط launcher) آمده. برچسب گوشه هر گزینه می‌گوید با API فعلی ساخته می‌شود یا کار اضافه به scope نسخه 1.0 اضافه می‌کند. رنگ اصلی را عوض کنید تا ببینید هر دیزاین با --gc-accent چطور می‌شود.
